# Midscene 用例写法

默认用自然语言描述步骤，不先写 locator。

## 步骤格式

每条用例至少包含：

- 目标
- 前置条件
- 页面入口
- 动作步骤
- 预期结果
- 失败观察点

## 示例

```md
### 用例：用户成功提交审批申请

- 前置条件：测试账号已登录，存在可提交的数据草稿
- 页面入口：审批中心首页
- 动作：
  1. 打开“审批中心”
  2. 进入“待提交”页签
  3. 选择第一条草稿并点击“提交”
  4. 在确认弹窗中点击“确认提交”
- 预期结果：
  - 页面出现成功反馈
  - 当前记录状态变为“已提交”
  - 列表数量同步变化
- 失败观察点：
  - 按钮是否不可点击
  - 弹窗是否缺失
  - 成功提示是否不明显
```

## 建议

- 每条用例聚焦一个用户目标
- 页面名称和按钮名称尽量贴近真实 UI 文案
- 如果页面内容依赖数据状态，明确写出前置数据
