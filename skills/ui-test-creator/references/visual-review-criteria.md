# 视觉与布局验收标准

视觉验收不是做设计评分，而是做“是否符合需求且看起来合理”的人工式评审。

## 检查维度

### 整体风格

- 是否符合需求语义
- 是否与产品定位一致
- 是否存在明显不协调的区域

### 信息层级

- 首屏是否能一眼看出主目标
- 标题、正文、辅助信息是否层级清楚
- CTA 是否足够突出

### 布局与版式

- 栅格和间距是否自然
- 内容是否拥挤或过空
- 关键模块是否摆放合理
- 表单、表格、详情页是否有明显失衡

### 文案与反馈

- 按钮文案是否符合动作语义
- 错误提示是否明确
- 成功反馈是否清楚
- 空状态、加载态、禁用态是否可理解

## 输出建议

每个页面至少写：

- 页面目标
- 做得好的地方
- 风险点
- 建议人工复核点
