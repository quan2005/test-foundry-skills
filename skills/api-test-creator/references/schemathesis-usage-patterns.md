# Schemathesis 使用模式

## 推荐模式

- `positive`
  已知 schema 较完整，先验证合法输入空间
- `negative`
  重点验证缺字段、错类型、非法值
- `all`
  同时需要正向和负向覆盖时使用

## 适合交给 Schemathesis 的内容

- 必填字段缺失
- 字段类型不正确
- 字符串过长或为空
- 数值越界
- 枚举非法值
- 响应结构偏离 schema

## 不适合交给 Schemathesis 的内容

- 跨接口业务流程
- 复杂状态流转
- 需要精确业务语义断言的场景
- 强依赖业务上下文的数据准备流程

## 计划输出建议

在 `schemathesis-plan.md` 中写清：

- 目标接口
- 使用模式
- 预期发现的问题类型
- 已知 schema 缺口
- 是否建议加入 CI
